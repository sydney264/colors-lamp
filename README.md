\# COLORS – LAMP Stack Web Application



\## Description



COLORS is a web application built using the LAMP stack.

It allows users to log in, add colors to their personal collection, and search through saved colors.



The application demonstrates RESTful API development, MySQL database integration, and client-server communication using JSON.



---

\- Linux

\- Apache

\- MySQL

\- PHP

\- JavaScript

\- HTML/CSS

\- cURL (for API testing)

\## Setup Instructions



1\. Install LAMP stack (Linux, Apache, MySQL, PHP).

2\. Create a MySQL database named `COP4331`.

3\. Create required `Users` and `Colors` tables.

4\. Place API files in Apache server directory.

5\. Access the application via a web browser.



---



\## Running the Application



\- Login using a valid user.

\- Add colors to your collection.

\- Search saved colors.



API endpoints:

\- Login.php

\- AddColor.php

\- SearchColors.php



All endpoints use POST requests with JSON.
